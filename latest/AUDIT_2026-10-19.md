## 재현 순서

```bash
git fetch origin vllm-v0320-sm80
git switch vllm-v0320-sm80
git pull --ff-only
bash latest/build_sif.sh

# NAME comes from latest/VERSION.env; override SIF_PATH when needed.
SIF_PATH="$PWD/deepseek-v41-flash-sm80-v0320-stage5-qa2-cu130.sif"

# First isolate Engram's prior JIT ABI error.
singularity exec --nv "$SIF_PATH" python3 /opt/deepseek-sm80/verify_sm80_engram.py

# Start text only. All checks run before model load.
SIF_PATH="$SIF_PATH" ENABLE_VISION=0 ENABLE_DSPARK=0 \
ALLOW_EXPERIMENTAL=1 MODEL_PATH=/models/DeepSeek-V4.1-Flash-1017 \
bash latest/serve_a100.sh

# After API startup (separate terminal):
python3 latest/verify_1017_serving_semantics.py --save outputs/no-spec.json

# Only after the above is correct, restart server with Vision on and
# verify Vision. DSpark must stay off while #62417 is unresolved.
```

**위 단계의 PASS 출력이 없다면 실제 모델 correctness는 확인되지 않았다.**
